How it works

From the share sheet on a track link, run UNI-SHARE, choose Apple Music, Deezer, Tidal, or Spotify, and the Shortcut asks this API for the match.

  1. Install the Shortcut once.
  2. Share any supported track URL into it.
  3. Pick your target service and open the result.

Add Shortcut

On iPhone or iPad, tap Add Shortcut to install. Allow Untrusted Shortcuts if iOS asks. The Shortcut calls the convert API and opens the destination link.
