UNI-SHARE

Install the Shortcut

One tap installs the signed UNI-SHARE Shortcut. On iPhone/iPad, allow Untrusted Shortcuts if iOS asks (Settings → Shortcuts). Prefer an iCloud link when SHORTCUT_INSTALL_URL is set on the server.

Add Shortcut Open blueprint

File install uses shortcut/UNI-SHARE.shortcut (signed for anyone). Apple’s one-tap iCloud import is smoother once you share the Shortcut from the Mac Shortcuts app and set SHORTCUT_INSTALL_URL.

After install

  1. Open the Shortcut named UNI-SHARE. The first Text action is labeled API Convert URL — set it to https://YOUR_HOSTNAME/api/v1/convert (same host as PUBLIC_BASE_URL).
  2. Optional: in Shortcuts, Share → Copy iCloud Link, then set SHORTCUT_INSTALL_URL in the server .env and restart so the landing Add Shortcut button uses that link.
