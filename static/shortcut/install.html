UNI-SHARE

Install the Shortcut

Apple only imports signed Shortcut files from iCloud or a Mac signing step. This page sets the API base URL and walks you through a one-time build in the Shortcuts app.

Open blueprint
  1. Open the Shortcuts app and create a new Shortcut named UNI-SHARE.
  2. Add Receive input from Share Sheet — accept URLs / Text.
  3. Add Choose from Menu with: Apple Music, Deezer, Tidal, Spotify.
  4. Under each menu item, set a Text value for the target: apple_music, deezer, tidal, spotify.
  5. Add Get Contents of URL. Method POST. URL = your convert endpoint (button above). Request body JSON: {"url":"Shortcut Input","target":"Menu Result"} (use Magic Variables for those fields). Header Content-Type: application/json.
  6. Add Get Dictionary Value for key url.
  7. Add Open URLs with that value.
  8. Optional: Share the Shortcut via iCloud, then set SHORTCUT_INSTALL_URL on the API host so Add Shortcut becomes one tap.

Details and a machine-readable action list live in blueprint.md.
