UNI-SHARE

Installer le raccourci

Un tap installe le raccourci signé UNI-SHARE. Sur iPhone/iPad, autorise les raccourcis non fiables si iOS le demande (Réglages → Raccourcis). Si SHORTCUT_INSTALL_URL est défini, le bouton utilise le lien iCloud.

Ajouter le raccourci Voir le plan

Installation via shortcut/UNI-SHARE.shortcut. Le lien iCloud reste le plus fluide une fois partagé depuis l’app Raccourcis Mac.

Après l’installation

  1. Ouvre le raccourci UNI-SHARE. La première action Texte s’appelle URL API de conversion — elle doit valoir https://TON_DOMAINE/api/v1/convert.
  2. Optionnel : Partager → Copier le lien iCloud, puis SHORTCUT_INSTALL_URL dans le .env du serveur.
